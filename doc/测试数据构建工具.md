# 测试数据构建工具

## 1. 目标

用于快速生成可扫描的本地照片目录结构，便于集成测试与手工联调。

## 2. 工具位置

- `service/src/bin/testdata_builder.rs`

## 3. 用法

在 `service` 目录执行：

```bash
cargo run --bin testdata_builder -- /tmp/xphoto_test_data
```

工具会在目标目录下构建多组目录（含自动建相册规则命名）并生成 JPG 文件。

## 4. EXIF 写入说明

- 工具会尝试调用系统 `exiftool` 写入 `DateTimeOriginal/CreateDate/ModifyDate`。
- 若本机没有 `exiftool`，会跳过 EXIF 写入并输出 warning。

建议安装：

```bash
exiftool -ver
```
