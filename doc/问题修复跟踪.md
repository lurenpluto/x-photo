# X-Photo 问题与修复跟踪

本文用于持续跟踪项目中的已知问题、修复计划、验证结果和下一步工作。新增问题先登记为 `TODO`；开始处理后改为 `IN_PROGRESS`；代码修复完成后改为 `FIXED`；对应验证通过后改为 `VERIFIED`。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| `TODO` | 已确认或高度疑似，需要修复或进一步验证。 |
| `IN_PROGRESS` | 正在修复或验证中。 |
| `FIXED` | 已完成代码或文档修复，但还需要补充验证结果。 |
| `VERIFIED` | 已通过对应验证，可以视为关闭。 |
| `WONTFIX` | 明确暂不修复，需要在备注中说明原因。 |

## 使用规则

- 每个问题必须有稳定编号，格式为 `XP-YYYYMMDD-NN`。
- 新发现的问题追加到“问题列表”，默认状态为 `TODO`。
- 修复时在“修复计划/处理记录”中写清楚变更范围。
- 验证后在“验证结果”中记录命令、结论和失败摘要。
- 文档、后端、前端、脚本、测试问题都放在同一张表中，便于判断下一步优先级。
