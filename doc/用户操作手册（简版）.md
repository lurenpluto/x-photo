# X-Photo 用户操作手册（简版）

面向日常使用者的 1 页说明：只保留最常用步骤。

## 1. 启动

在项目根目录执行：

- Linux/macOS: `./start.sh`
- Windows PowerShell: `.\start.ps1`
- Windows CMD: `start.bat`

启动成功后打开：`http://127.0.0.1:55081`

## 2. 停止

- Linux/macOS: `./stop.sh`
- Windows PowerShell: `.\stop.ps1`
- Windows CMD: `stop.bat`

## 3. 首次使用

1. 进入 `设置` 页。
2. 在 Source 区域填写照片目录路径并创建。
3. 触发扫描。
4. 回到 `照片` 页查看结果。

## 4. 页面功能

- `照片`：按时间查看、搜索、筛选、打开详情。
- `收藏`：查看收藏照片，快速取消收藏。
- `相册`：浏览相册并进入相册详情。
- `设置`：配置 API、管理 Source、触发扫描。
- `状态`：查看任务进度、失败原因、重试任务。

## 5. 搜索怎么用

支持普通关键词，也支持字段前缀：

- `album:` 按相册名
- `remark:` 按备注
- `camera:` 按相机
- `lens:` 按镜头
- `date:` 按日期（如 `date:2025-12`）

示例：

- `album:旅行`
- `camera:iPhone date:2025-12`

## 6. 常用快捷键

- `/`：聚焦搜索框
- `Esc`：返回上一级
- `←` / `→`：分页或切换上一张/下一张
- `+` / `-` / `0`：缩放详情图片

## 7. 常见问题

- 页面打不开：确认 Web 是否在 `55081` 端口运行。
- 列表为空：确认 Source 路径正确且扫描已完成。
- API 报错：在 `设置` 页面检查 API Base（默认 `http://127.0.0.1:55080/rpc/v1`）。
- 图片不显示：检查本地目录权限与文件是否存在。

## 8. 日志位置

- 后端日志：`.service.log`（错误日志：`.service.err.log`）
- 前端静态服务日志：`.web.log`（错误日志：`.web.err.log`）
