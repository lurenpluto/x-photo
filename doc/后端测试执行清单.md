# 后端测试执行清单

## 1. 生成测试数据

```bash
cd service
cargo run --bin testdata_builder -- /tmp/xphoto_test_data --strategy family_us_weekends_2025 --year 2025 --seed 42
```

## 2. 启动后端服务

```bash
cd service
cargo run
```

## 3. 执行 smoke 测试脚本

```bash
cd service
BASE_URL=http://127.0.0.1:8080/rpc/v1 DATA_DIR=/tmp/xphoto_test_data ./scripts/smoke_test.sh
```

## 4. 执行自动化测试

```bash
cd service
cargo test
```

重点集成测试：

- `tests/scan_workflow.rs`：扫描入库+自动建相册
- `tests/task_control.rs`：失败扫描重试+任务总览接口
- `tests/error_recovery.rs`：取消收敛、重复触发拒绝、坏文件容错
