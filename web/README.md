# X-Photo Web Console (V1)

这是一个零构建前端控制台，用来快速联调后端 V1 能力（source、scan、task、album、photo-search）。

## 运行方式

1. 启动后端服务：

```bash
cd service
cargo run
```

2. 启动静态文件服务：

```bash
cd web
python -m http.server 5174
```

3. 打开页面：

`http://127.0.0.1:5174`

页面默认 API Base 为 `http://127.0.0.1:8080/rpc/v1`，可在页面右上角改成任意地址。

## 当前能力

- 三段式路由页面：`#resources`、`#tasks`、`#photos`。
- 资源管理：创建/查看 Source、触发扫描、相册列表浏览。
- 任务中心：任务总览 + 任务列表 + 任务详情（状态流、错误信息、重试/取消操作）。
- 任务中心：任务页签下自动轮询刷新（3 秒）并显示最近刷新时间。
- 照片浏览：支持按相册/时间区间筛选、分页浏览、详情抽屉、备注编辑、加入相册。
- 照片浏览：筛选与分页状态会同步到 URL 查询参数，刷新后可恢复。
- 快捷键：`/` 聚焦搜索框，`←/→` 分页（或抽屉内切图），`Esc` 关闭抽屉。
- 照片浏览：支持切换时间排序（正序/倒序），并展示当前筛选 chips。
- 抽屉支持上一张/下一张，以及从指定相册移除当前照片。

## 说明

- 后端已加通用 CORS，便于前端独立端口联调。
- 该页面定位为 V1 管理控制台，后续可逐步拆分为正式产品信息架构与页面路由。
