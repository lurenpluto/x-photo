# X-Photo Web Console (V1)

这是一个零构建前端控制台，用来快速联调后端 V1 能力（source、scan、task、album、photo-search）。

## 运行方式

1. 启动后端服务：

```bash
cd service
cargo run
```

2. 启动静态文件服务：

```bash
cd web
python -m http.server 5174
```

3. 打开页面：

`http://127.0.0.1:5174`

页面默认 API Base 为 `http://127.0.0.1:8080/rpc/v1`，可在页面右上角改成任意地址。

当前默认仅本机访问（后端监听 `127.0.0.1:8080`）。若后续要开放外部访问，请先补齐认证与安全策略，再通过 `BIND_ADDR` 调整监听地址。

## 当前能力

- 左侧固定四个标签：`照片`、`相册`、`设置`、`状态`。
- 默认进入 `照片` 标签，右侧先展示最新相册，再展示瀑布流最新照片。
- `相册` 标签独立展示相册网格，便于快速浏览。
- 点击相册/照片会在右侧进入详情子页面，左侧 tab 保持不变；可通过顶部返回按钮回到之前状态。
- 详情页区分两个返回动作：`后退`（回到上一个详情）与 `返回上一级`（直接回到列表页）。
- 照片详情页提供大图预览区 + 右侧信息面板，交互接近相册类产品查看模式。
- 照片详情页增加沉浸式顶部工具条与地点信息卡片，可直接跳转地图查看位置。
- 照片详情页支持 EXIF 参数展示，并支持滚轮/快捷键缩放与拖拽查看大图。
- 照片详情右侧信息区支持折叠分组；支持双击按焦点放大/还原。
- 图片平移已增加边界约束，并显示实时缩放倍率；相册详情卡片提供悬浮预览入口。
- 相册详情照片与主照片页统一为按日期分组瀑布流，图片加载带淡入过渡与操作提示。
- 新增轻量 toast 反馈与快捷键帮助面板（`?`）提升可感知性。
- 照片详情将文件路径与来源ID下沉到“高级信息”折叠区，默认只展示常用信息。
- 时间戳展示统一到秒级（如 `YYYY-MM-DD HH:mm:ss`），避免纳秒噪声。
- 相册卡片展示统一为“相册名 + 照片数量”两行，并保持等尺寸网格风格。
- 关键词搜索已覆盖：文件名、路径、备注、EXIF文本、相册名称。
- 支持字段化关键词：`album:`、`remark:`、`exif:`、`camera:`、`lens:`、`path:`、`source:`、`date:`。
- 搜索框下方提供前缀快捷按钮与示例提示，可一键插入字段前缀。
- 支持侧栏折叠模式（状态持久化），详情右栏独立滚动，提升宽屏可用空间利用率。
- 相册详情页支持关键词/时间/排序筛选与分页，并可在相册内继续打开照片详情。
- `设置` 标签聚合连接配置、健康检查、Source 创建与触发扫描。
- `状态` 标签独立展示任务总览、任务列表、任务详情与取消/重试操作。
- 照片支持按关键词/相册/时间/排序筛选，支持分页、详情抽屉、备注、加减相册。
- 照片筛选与分页状态会同步到 URL 查询参数，刷新后可恢复。
- 快捷键：`/` 聚焦搜索框，`←/→` 分页或抽屉切图，`Esc` 关闭抽屉。

## 说明

- 后端已加通用 CORS，便于前端独立端口联调。
- 该页面定位为 V1 管理控制台，后续可逐步拆分为正式产品信息架构与页面路由。
