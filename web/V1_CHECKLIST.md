# X-Photo Frontend V1 Checklist

## 目标

在不引入前端构建链的前提下，完成可联调、可演示、可验证的 V1 网页控制台。

## 执行步骤（已按顺序推进）

1. [x] 建立基础控制台：健康检查、Source、任务、相册、照片检索。
2. [x] 拆分信息架构：资源管理 / 任务中心 / 照片浏览。
3. [x] 任务中心增强：任务详情、状态流、取消/重试任务与扫描。
4. [x] 照片详情抽屉：查看详情、保存备注、加入相册。
5. [x] 照片检索增强：相册+时间筛选、分页、排序切换、筛选 chips。
6. [x] 交互增强：URL 状态恢复、快捷键、抽屉内上一张/下一张。
7. [x] 相册关系操作：从抽屉内将照片从相册移除。
8. [x] 任务中心自动轮询：3 秒刷新任务总览/列表/详情。
9. [x] 文档补充：运行方式、能力说明、快捷键、联调说明。
10. [x] 回归验证：后端关键集成测试持续通过。

## 下一阶段（V1+）

- 抽离 API 客户端与视图模块，降低 `app.js` 复杂度。
- 增加前端自动化测试（建议 Playwright）。
- 对关键操作补充 toast 与确认弹窗（避免误操作）。
